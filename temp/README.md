# Temporary Directory (`temp/`)

Direktori ini digunakan **khusus untuk file sementara (ephemeral / scratchpad)** selama sesi pengerjaan lokal yang tidak memiliki tempat khusus permanen.

- Jangan menyimpan dokumentasi permanen di sini (simpan di `docs/`).
- Jangan menyimpan script atau laporan hasil tes di sini (simpan di `test/` dan `test/results/`).
- Isi folder ini dikecualikan dari version control via `.gitignore`.
